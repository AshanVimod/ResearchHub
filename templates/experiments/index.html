Logging from Jupyter

Add the project's scripts folder to the notebook's path once, then call log_run. If the app isn't running, the run is saved to experiments_pending.jsonl and imported the next time the app starts.

import sys; sys.path.append(r"{{ config_scripts }}")
from log_experiment import log_run
log_run(run_name="rf_baseline_v1", approach="baseline", model="RandomForest",
        data_version="v1", split_desc="5-fold cross-validation",
        params={"n_estimators": 200, "max_depth": 8},
        metrics={"accuracy": 0.86, "f1": 0.81, "roc_auc": 0.90},
        notebook_path="notebooks/02_baseline.ipynb")
